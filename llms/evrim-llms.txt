# Evrim

> Evrim is the upstream signal layer for U.S. financial institutions, the defense industrial base, and federal agencies. The Evrim REST API (v0.5.18, "Data when and how you want it.") builds structured intelligence Profiles from reusable Templates and Fields, captures point-in-time Snapshots, and extracts values and relationships from source content. Authentication is a Knox-issued API token presented as an HTTP Bearer credential.

## APIs

- [Evrim API](https://api.evrim.ai): Production REST API base URL. 91 operations across profiles, templates, fields, snapshots, extract, collections, tags, answers, costs, and health.
- [OpenAPI (original)](https://raw.githubusercontent.com/api-evangelist/evrim/refs/heads/main/openapi/evrim-openapi-original.yml): OpenAPI 3.0.3 harvested from the Stainless SDK spec.

## SDKs

- [evrim (Python)](https://pypi.org/project/evrim/): Official Python library (Python 3.8+), sync + async httpx clients. `pip install evrim`. Source: https://github.com/evrimai/python-client

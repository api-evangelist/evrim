# Evrim

> Evrim is the upstream signal layer for U.S. financial institutions, the defense industrial base, and federal agencies. The Evrim REST API (v0.5.18, "Data when and how you want it.") builds structured intelligence Profiles from reusable Templates and Fields, captures point-in-time Snapshots, and extracts values and relationships from source content. Authentication is a Knox-issued API token presented as an HTTP Bearer credential. Evrim does not publish an llms.txt of its own; this file is generated by API Evangelist from the repo's artifacts.

## APIs

- [Evrim API](https://api.evrim.ai): Production REST API base URL. 91 operations across profiles, templates, fields, snapshots, extract, collections, tags, answers, costs, and health. Note: the documented `/prod/v0/` paths return 404 on the live host today — see the lifecycle artifact.
- [OpenAPI (original)](https://raw.githubusercontent.com/api-evangelist/evrim/refs/heads/main/openapi/_original/evrim-openapi-original.yml): OpenAPI 3.0.3 harvested from the Stainless SDK spec.

## Agent surfaces

- [MCP endpoint](https://api.evrim.ai/mcp): Live remote Model Context Protocol server (Streamable HTTP). Requires an `Authorization: Bearer <Knox API token>` credential — an anonymous `tools/list` returns 401 with `www-authenticate: Bearer`, so the tool list cannot be read without credentials. No OAuth discovery metadata is served, so the token must be supplied out of band.
- Legacy SSE transport is also present at https://api.evrim.ai/sse (401, gated).
- No A2A agent card is published on any Evrim host.

## SDKs

- [evrim (Python)](https://pypi.org/project/evrim/): Official Python library (Python 3.8+), sync + async httpx clients. `pip install evrim`. Latest release 2.8.0, published 2025-03-27. Source: https://github.com/evrimai/python-client

## Access

- No public pricing, plans or rate limits are published. Access is sales-gated; the product itself lives behind a login at https://handshake.evrim.ai/login.
